Keys

↑ ↓
Pick a commit, or a file in the tree
Enter
Open the picked file's diff
Alt+↑ Alt+↓
Previous or next file's diff
F7 · Shift+F7
Next or previous change, on into the next or previous file
Ctrl+Enter
Push; in the commit message, Commit
Ctrl+Shift+Enter
In the commit message: Commit and Push
Space
Tick or untick an uncommitted file or folder
Ctrl+Alt+Z
Roll back the picked uncommitted file or folder
Ctrl+F
Search the commits; Esc clears the search
F5
Fetch and read again
Ctrl+1 … 9
Switch repo
Ctrl+B
Show or hide the branches
Enter, double-click
Switch to the picked branch
F2 · Del
Rename or delete the picked branch or folder
Ctrl+Shift+N
New branch from HEAD
Esc
Close the diff, then the window
